## 📌 Project Overview
This repository documents the end-to-end execution, artifacts, and evolution of the **WORKFAIR** research project throughout the semester. 

Building upon our approved research proposal, this study investigates university group project collaboration dynamics, identifies key bottlenecks in workload equity and progress transparency, and develops data collection instruments, empirical analyses, and system specifications for an integrated academic accountability platform.

## 📁 Repository Structure
In accordance with the course research project requirements, this repository is organized into the following directories:

```text
/
├── proposal/          # Approved research proposal and initial concept papers
├── instruments/       # Survey questionnaires, interview protocols, and evaluation rubrics
├── pilot-study/       # Pilot testing data, feedback, and instrument refinement notes
├── data/              # Cleaned, anonymized empirical datasets (CSV, Excel)
├── analysis/          # Data analysis scripts, statistical models, and outputs (Python, R, SPSS)
├── report/            # Final research report drafts and finalized submission PDF
├── presentation/      # Presentation slide decks and defense materials
├── meeting-notes/     # Weekly meeting minutes, action items, and sprint summaries
├── references/        # Academic literature, APA 7th citations, and benchmark sources
└── README.md          # Project guide, folder documentation, and replication steps
```
